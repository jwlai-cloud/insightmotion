# Learning notes

- **Next.js route handlers** keep OpenAI calls server-side while shipping UI
  and API in one deployment.
- **GPT-5.6 Terra** balances model quality and live-demo cost. The API route
  uses Chat Completions structured JSON to request code plus user-facing result
  fields in one response.
- **three.js** owns WebGL scene/camera/render loop. **anime.js 3.2.2** keeps
  compatibility with the provided prototype's generated-code contract.
- **URL query parameters** provide a zero-database share mechanism: state is
  inspectable, copyable, and reruns fresh on load.
- **Signed HTTP-only cookie** limits accidental public API spend without
  building accounts.
- **Data abstraction:** the same live-generation loop accepts a retail dataset
  or simulated global football tournament aggregate engagement operations review. The model receives only
  selected scenario data and must use it rather than inventing metrics.
